# python-more_classes

Python project on classes and objects: class and instance attributes,
properties, `__str__` / `__repr__` / `__del__`, static and class methods.

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- pycodestyle 2.7.*
- First line of every file: `#!/usr/bin/python3`
- All files executable and ending with a new line
- All modules, classes and functions are documented

## Files
| File | Description |
|------|-------------|
| 0-rectangle.py | Empty class `Rectangle` |
| 1-rectangle.py | Validated `width` and `height` (properties) |
| 2-rectangle.py | Adds `area()` and `perimeter()` |
| 3-rectangle.py | Adds `__str__` (prints with `#`) |
| 4-rectangle.py | Adds `__repr__` usable with `eval()` |
| 5-rectangle.py | Adds `__del__` ("Bye rectangle...") |
| 6-rectangle.py | Adds `number_of_instances` class attribute |
| 7-rectangle.py | Adds `print_symbol` class attribute |
| 8-rectangle.py | Adds static method `bigger_or_equal` |
| 9-rectangle.py | Adds class method `square` |
