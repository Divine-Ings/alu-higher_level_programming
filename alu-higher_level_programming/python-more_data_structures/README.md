# python-more_data_structures

Python project covering list comprehensions, sets, dictionaries, and `map`.

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- pycodestyle 2.7.*
- First line of every file: `#!/usr/bin/python3`
- All files executable and ending with a new line

## Files
| File | Description |
|------|-------------|
| 0-square_matrix_simple.py | Squares every value of a matrix (new matrix) |
| 1-search_replace.py | Replaces all occurrences of an element in a new list |
| 2-uniq_add.py | Adds all unique integers of a list |
| 3-common_elements.py | Set of common elements of two sets |
| 4-only_diff_elements.py | Set of elements present in only one set |
| 5-number_keys.py | Number of keys in a dictionary |
| 6-print_sorted_dictionary.py | Prints a dictionary by sorted keys |
| 7-update_dictionary.py | Replaces or adds a key/value |
| 8-simple_delete.py | Deletes a key in a dictionary |
| 9-multiply_by_2.py | New dictionary with all values multiplied by 2 |
| 10-best_score.py | Key with the biggest integer value |
| 11-multiply_list_map.py | Multiplies list values using `map` (max 3 lines) |
| 12-roman_to_int.py | Converts a Roman numeral to an integer |
