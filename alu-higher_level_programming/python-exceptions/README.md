# python-exceptions

Python project covering error handling: `try` / `except` / `else` / `finally` and `raise`.

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- pycodestyle 2.7.*
- First line of every file: `#!/usr/bin/python3`
- All files executable and ending with a new line

## Files
| File | Description |
|------|-------------|
| 0-safe_print_list.py | Prints x elements of a list safely, returns the count printed |
| 1-safe_print_integer.py | Prints an integer with `"{:d}".format()`, returns True/False |
| 2-safe_print_list_integers.py | Prints only the integers among the first x elements |
| 3-safe_print_division.py | Divides two integers, prints the result in `finally` |
| 4-list_division.py | Divides two lists element by element with error handling |
| 5-raise_exception.py | Raises a `TypeError` |
| 6-raise_exception_msg.py | Raises a `NameError` with a message |
