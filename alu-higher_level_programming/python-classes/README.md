# python-classes

Python project introducing classes and objects: private attributes,
properties (getters/setters), validation, and printing.

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- pycodestyle 2.7.*
- First line of every file: `#!/usr/bin/python3`
- All files executable and ending with a new line

## Files
| File | Description |
|------|-------------|
| 0-square.py | Empty class `Square` |
| 1-square.py | `Square` with a private `size` |
| 2-square.py | Adds type/value validation of `size` |
| 3-square.py | Adds `area()` |
| 4-square.py | Adds `size` getter and setter (property) |
| 5-square.py | Adds `my_print()` that prints the square with `#` |
| 6-square.py | Adds `position` (property) used by `my_print()` |
