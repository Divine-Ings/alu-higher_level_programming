# python-input_output

Python project on input/output: reading and writing files, the `with`
statement, JSON serialization and deserialization, and command-line arguments.

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- pycodestyle 2.7.*
- First line of every Python file: `#!/usr/bin/python3`
- All files end with a new line and all Python files are executable
- All modules, classes and functions are documented

## Files
| File | Description |
|------|-------------|
| 0-read_file.py | Reads a text file and prints it to stdout |
| 1-write_file.py | Writes a string to a text file (overwrites), returns characters written |
| 2-append_write.py | Appends a string to a text file, returns characters added |
| 3-to_json_string.py | Returns the JSON string of an object |
| 4-from_json_string.py | Returns the object represented by a JSON string |
| 5-save_to_json_file.py | Writes an object to a file as JSON |
| 6-load_from_json_file.py | Creates an object from a JSON file |
| 7-add_item.py | Adds command-line arguments to `add_item.json` |
| 8-class_to_json.py | Dictionary description of an object |
| 9-student.py | `Student` with `to_json()` |
| 10-student.py | `Student.to_json(attrs)` with an attribute filter |
| 11-student.py | `Student` with `reload_from_json()` |
| 12-pascal_triangle.py | Pascal's triangle of n rows |
