# python-data_structures

Python project covering lists, tuples, sequences, and the `del` statement.

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- pycodestyle 2.7.*
- First line of every file: `#!/usr/bin/python3`
- All files executable and ending with a new line

## Files
| File | Description |
|------|-------------|
| 0-print_list_integer.py | Prints all integers of a list |
| 1-element_at.py | Safely retrieves an element at an index |
| 2-replace_in_list.py | Replaces an element at an index (in place) |
| 3-print_reversed_list_integer.py | Prints integers of a list in reverse |
| 4-new_in_list.py | Replaces an element in a copy of the list |
| 5-no_c.py | Removes all `c` and `C` from a string |
| 6-print_matrix_integer.py | Prints a matrix of integers |
| 7-add_tuple.py | Adds two tuples (first 2 elements) |
| 8-multiple_returns.py | Returns (length, first character) of a string |
| 9-max_integer.py | Finds the biggest integer without `max()` |
| 10-divisible_by_2.py | List of booleans: is each integer a multiple of 2 |
| 11-delete_at.py | Deletes the item at a position without `pop()` |
| 12-switch.py | Swaps `a` and `b` |
