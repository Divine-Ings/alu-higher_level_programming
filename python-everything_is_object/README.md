# python-everything_is_object

Python project on how everything is an object: `id()` and `type()`, mutable
vs. immutable objects, aliasing, and how arguments are passed to functions.

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- pycodestyle 2.7.*
- First line of every Python file: `#!/usr/bin/python3`
- All files end with a new line

## Files
| File | Description |
|------|-------------|
| 0-answer.txt ... 18-answer.txt | Answers to the quiz-style tasks |
| 19-copy_list.py | Returns a copy of a list (max 3 lines) |
| 20-answer.txt ... 28-answer.txt | Answers to the quiz-style tasks |
| 29-blog_post.md | Draft of the blog post (task 29) |
